## 1. Getting started

**Open the admin:** go to your website address followed by `/admin/login`.

Sign in with the email and password you were given.

**First time in?** Change your password immediately: click your name (bottom of
the left menu) → **Admins** → your own row → set a new one. Never share a login;
if someone else needs access, give them their own account (section 19). The
website records who changed what, and shared logins make that record useless.

**Forgot your password?** There is no self-service reset. Ask a Super Admin to
set a new one for you from the Admins screen.

---

## 2. How the screen is laid out

**Left side — the menu.** Every part of the website you can edit. Two entries
open out into a list when you click them:

- **Homepage** — the sections of the front page
- **Page Content** — every public page (IQAC, NAAC, Syllabus, …)

**Top — search.** Type what you want ("faculty", "iqac", "syllabus") and it
takes you straight there. Quicker than hunting through the menu.

**Middle — your work area.**

**A guided tour** runs the first time you log in. To see it again, look for the
help/tour button in the top bar.

---

## 3. Five rules worth knowing first

**1. Changes go live immediately.** There is no "publish" step for most content.
When you press Save, visitors see it. Read it once more before saving.

**2. Delete is safe.** Deleted items go to **Recently deleted** at the bottom of
the screen, with a **Restore** button. They are not gone forever.

**3. It always asks before saving or deleting.** If you did not mean to press
it, choose Cancel.

**4. Everything is recorded.** Your name, the time, and what changed. See
section 20.

**5. Upload once, use anywhere.** A file uploaded to the Media Library can be
used on any number of pages. Do not upload the same photo five times.

## 4. Media Library

**Menu → Media Library.** Every photo, video and PDF on the website lives here.

### Uploading

1. Click **Upload** (or drag files straight onto the page — that works too)
2. Pick one file or many at once
3. Wait for the spinner to finish — large videos take a while

### The "Show on page" box — read this before uploading

Above the upload button there is a **Show on page** dropdown. If you choose a
page *before* uploading, the file is added to that page automatically.

- Upload a **photo** with "IQAC" selected → it joins the IQAC page's gallery
- Upload a **PDF** with "IQAC" selected → it joins IQAC's documents
- Leave it blank → the file just sits in the library until you use it

### Finding things again

Files are grouped by the day you uploaded them — **Today**, **Yesterday**, then
by date. Each file also shows a small tag saying where it is used, e.g.
`Document · IQAC`, or **"Not used yet"**.

Use **folders** (left side) to organise: one per department, one for events, and
so on. Search and the type filters (Images / Videos / Documents) help too.

### Replacing a file

Open the file → **Replace**. Everywhere that file appears updates at once — you
do not need to re-add it to each page. Use this for an updated brochure or a
corrected photo.

### Deleting

Open the file → **Delete**.

If it is used somewhere, the system tells you where and stops you. Remove it
from those pages first. (Gallery items are the exception — deleting the file
removes the gallery entry with it, so pages never show a broken image.)

## 5. Page Content

**The easiest screen in the system.** Use this when you think *"I want to put
something on the IQAC page"* rather than *"I want to add a document"*.

**Menu → Page Content** opens a list of every page. Click one — IQAC, NAAC,
Syllabus, Examinations, a department — and you see everything on it:

- **Documents** on that page — with Delete
- **Images** on that page — with Remove
- **Videos** on that page — with Remove
- Buttons to **add** a document, image or video

Some pages (Fee Structure, Courses & Intake, Regulations, Admissions) also show
**Text tables** — see section 21 for editing those.

**This is the recommended way to update a page.** Everything for that page is in
one place, instead of hunting through Documents, then Gallery, then Media.

## 6. Homepage

**Menu → Homepage** opens into its sections. Each is edited separately:

| Section | What it controls |
|---|---|
| **Hero Banner** | The big video/heading at the top, and the two buttons |
| **Statistics** | The number tiles (students, faculty, placements) |
| **Quick Links** | The shortcut cards |
| **Vision / Mission / About** | Those text blocks |
| **Admissions** | The admissions promo area |
| **Departments** | Which department cards show, and their order |
| **Testimonials** | Student and alumni quotes |
| **Campus Videos** | The video strip |
| **Accreditation** | NAAC / NBA / AICTE badges |
| **Recruiters** | Company logos |

**Reordering:** drag an item by its handle. The new order saves immediately.

**Hiding a section without deleting it:** Site Settings → Homepage sections has
on/off switches. Turning one off hides it from visitors but keeps the content —
useful for a section you only want live during admissions season.

### ⚠️ Careful with numbers

Statistics use a number box. **Do not scroll the mouse wheel while your cursor
is over it** — in some browsers that changes the value. Click away first, then
scroll. (A stat typed as 32 was once saved as -8 this way.)

## 7. Departments

**Menu → Departments**, then click a department. It opens a workspace with tabs,
each covering one part of that department's page:

| Tab | Contents |
|---|---|
| **Overview** | Name, tagline, about text, hero image |
| **Faculty & HOD** | Staff list, photos, the HOD and their message |
| **Programmes** | Courses offered and intake |
| **Laboratories** | Labs, descriptions, equipment, photos |
| **PEO / PO / PSO** | Learning outcomes |
| **Highlights & Achievements** | Notable points and awards |
| **Research** | Publications, projects, patents |
| **Gallery** | That department's photos |
| **Videos** | That department's videos |
| **Documents** | Syllabus, forms, notices — set the category |
| **Contact Information** | Department contacts |
| **Statistics** | Department-level numbers |
| **Display Settings** | Show/hide each section of the page |

**Display Settings is worth knowing.** Every section can be switched off
individually — for example, hide the Research section for a department that has
not published yet, without deleting anything.

**Faculty photos** are controlled globally: Site Settings → one switch turns
photo cards on or off for *every* department at once.

## 8. Gallery

**Menu → Gallery.** The site-wide photo and video gallery.

**Adding:**
1. **Add image or video**
2. Choose **Image** or **Video** at the top — this matters, it decides what you
   can upload
3. Give it a title, pick the file (drag and drop works)
4. Set a **Category** (Campus, Labs, Sports, Events…) — this drives the filter
   buttons visitors use. Videos are grouped automatically under "Videos".
5. Optionally choose **Show on page** to put it on a specific page too

**Reordering:** drag. **Deleting:** Delete, then Restore from Recently deleted
if you change your mind.

---

## 9. Documents

**Menu → Documents.** Every downloadable file — syllabus, question papers,
brochures, forms, affidavits.

**Adding:**
1. **Add download**
2. **Title** — what visitors see, so write it properly: "B.Tech R23 CSE
   Syllabus", not "syllabus1"
3. **Category** — Syllabus, Question Papers, Brochure, Form, Affidavit, Other
4. **Show on page** — which page it appears on
5. **Group label** (optional) — a heading like "AY 2025-26" to group documents
   together on the page
6. Pick the file

**The Page column and filter** let you narrow to one page's documents — the
quickest way to find and remove something.

**Add each document once.** If a document belongs to a department, add it in
that department's Documents tab: it then appears on both the department page and
the relevant college-wide page automatically. Adding it twice creates two
entries.

## 10. News

**Menu → News.** News articles.

Add a title, the content, optionally an image and a date. Use **Active** to take
an item off the site without deleting it. News also feeds the homepage's news
area.

## 11. Events

**Menu → Events.** Upcoming and past events.

Title, description, date, optional image. Past events stay on the site as a
record unless you set them inactive.

---

## 12. Announcements

**Menu → Announcements.** These are the short notices that **scroll across the
top of the site**.

1. **Add announcement**
2. **Title** and, if you want, a shorter **display text** for the ticker
3. **Priority** — Critical (red), High (amber), Normal (blue), Low (grey)
4. **Link** (optional) — where clicking it takes the visitor
5. **Placement** — choose **Header Ticker** for the scrolling bar

**One announcement shows in several places.** A Header Ticker announcement also
appears in the homepage's "Latest Updates" panel. Write it once.

Speed, how many show at a time, and pause-on-hover are in Site Settings.

---

## 13. Exam Notifications

**Menu → Exam Notifications.** Hall tickets, timetables, results.

1. **Add notification**
2. **Title** — e.g. "B.Tech VI Sem Hall Tickets Released"
3. **Button text** — e.g. "Download Hall Ticket"
4. **File or link** — either **upload a PDF** (drag and drop works) **or** open
   "Or paste a URL directly" to link an external results page (e.g. the JNTUA
   portal). Both are normal.
5. **Academic year** — pre-filled with the current year (e.g. AY 2026-27)
6. **Start date**, and an **end date** if it should disappear on its own

**Academic year grouping:** the public page groups notifications by year, newest
first, with previous years underneath. The year rolls over automatically each
June, so next year's uploads simply go under the new heading.

Exam notifications also appear in the top ticker and the homepage updates panel.

## 14. Careers

**Menu → Careers** — job openings. Title, description, whether it is Active.

**Menu → Job Applications** — what candidates submitted. You can view each
application, download the CV, and move it through the pipeline (Received →
Shortlisted → Interviewed → Selected / Rejected). You can also export the list.

Applications cannot be deleted — they are a record. Correct them by changing the
status instead.

## 18. Site Settings

**Menu → Site Settings.** Global settings. Each block has its own **Save**
button — you only save the block you edited.

- **Branding** — college name, logo, favicon, motto, footer line, and the
  flower animation over the founder's portrait
- **Popup Notice** — a poster that greets visitors on the homepage (section 21)
- **Contact Information** — address, phone, email, map
- **Social links** — leave blank to hide an icon
- **Announcements** — ticker speed, how many show, pause on hover
- **Homepage sections** — show/hide each homepage block
- **Faculty photos** — one switch for all departments
- **SEO defaults** — the title and description search engines fall back to
- **Media limits** — maximum upload sizes

## 19. Admins, Roles & Permissions

*Super Admins only.*

**Admins** — create accounts. Give each person their own.

**The Department field matters.** Set it to CSE and that person can only edit
CSE content — faculty, labs, outcomes, gallery, documents, everything. They
cannot touch ECE, and the system enforces it, not just hides it. Leave it blank
for someone who should manage the whole site.

**Roles & Permissions** — what a person can *do* (view / add / edit / delete),
module by module. Role and department work together: "CSE + Editor" means they
can edit CSE and nothing else.

Give the least access that lets someone do their job. It is easy to add more.

## 20. Audit Logs

**Menu → Audit Logs.** Every change: who, what, when, and the before/after.

Filter by person, module or date. Use it to answer "who removed that notice?"
or to check a new staff member's early edits.

## 21. Common tasks

### Put a new syllabus on the website
Departments → your department → **Documents** → Add → Category **Syllabus** →
upload → Save. It appears on the department page *and* the Syllabus page.

### Show a poster to everyone visiting the site
Site Settings → **Popup Notice** → switch on → choose the poster image →
optionally a link (e.g. `/admissions`) → Save. It appears once per visit, after
the intro animation, and visitors close it with ✕. **Switch it off when the
event is over.**

### Change the fee table for next year
Page Content → **Academics → Fee Structure** → under **Text tables**, click any
cell and type → **Save table**. Add or remove rows with the buttons. No
developer needed.

### Put a notice in the scrolling bar
Announcements → Add → Placement **Header Ticker** → set the priority → Save.

### Add a video to a page
Page Content → pick the page → **Add video** → upload → Save.
(Or Media Library → choose the page in "Show on page" → upload the video.)

### Take something off the site without deleting it
Set **Active** to off. It stays in the admin, invisible to visitors.

### Recover something deleted by mistake
Scroll to **Recently deleted** on the same screen → **Restore**.

### Replace a document with a newer version
Media Library → find the file → **Replace** → upload the new one. Every page
using it updates at once, and the link visitors have keeps working.

## 22. When something looks wrong

**I saved but the website looks the same.**
Refresh with `Ctrl` + `Shift` + `R` — your browser is showing a cached copy.
Check the item is set **Active**, and that its section is not hidden in Display
Settings or Site Settings.

**The upload fails or spins forever.**
Check the file size — there are limits in Site Settings, and very large videos
take time. If it fails immediately with a size error, ask your technical team to
raise the upload limit on the server.

**An image shows as a broken icon.**
The file was probably deleted from the Media Library while a page still pointed
at it. Re-pick the image on that page.

**"Property … should not exist" or a red error bar.**
Note the exact wording and which screen you were on, and send it to your
technical team — that message tells them exactly what to fix.

**I cannot see a menu item.**
Your account does not have permission for it. A Super Admin can grant it.

**Someone changed something and I do not know who.**
Audit Logs. Filter by module and date.
